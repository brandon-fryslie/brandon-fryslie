# GitHub Stats

The [Live GitHub Stats card](./README.md) at the top of the profile is a fresh, animated data-visualization authored every day by the `stats` job. This page is where it links to.

Below is a set of **browse tiles** — each one is a permanent, hand-crafted badge that links into the live GitHub page behind that metric. They carry no numbers on purpose: the tile is the *category*, and clicking it takes you to the current, real count on GitHub. This section is hand-curated and is not touched by automation.

Why some tiles share a destination: **PRs Reviewed** and **Contributions** both point at the contribution overview rather than a search query. Those numbers on the daily card are sourced from GitHub's GraphQL `contributionsCollection`, whose canonical home *is* the contribution graph — a `reviewed-by:` search would report a different number and contradict the card. Search-backed counts (commits, merged PRs, closed issues) link to the search UI, which browses the same items the card counts.
