# Daily Stats Cards

Every "Live GitHub Stats" card that has appeared on this profile, newest first. The card at the top of [README.md](./README.md) is overwritten every morning; this page is where the previous ones keep living.

The gallery between the `<!-- STATS-GALLERY:START -->` and `<!-- STATS-GALLERY:END -->` markers below is generated by `.github/scripts/sync-stats-archive.py` from the files in [`stats-archive/`](./stats-archive/). Which days appear is recovered from this repository's git history. Nothing here is hand-maintained — see [`stats-archive/README.md`](./stats-archive/README.md) for how that works and why.

From August 2026 the card is composed fresh each morning by a Claude invocation reading a rich data seam, so the *shape* of the picture changes daily along with the data it encodes. Cards through July 2026 were drawn by a deterministic generator instead — the same four-tile layout every day, only the numbers moving — and those are being **remastered**: redrawn by the same daily process, from the same day's real numbers reconstructed as of that day. A remastered card is not the card that was live that morning; it is a better drawing of what that morning's data actually said.

Captions carry each day's headline numbers so the gallery can be skimmed without opening anything. A handful of the earliest not-yet-remastered cards have no caption — those predate the data seam and did not render their metrics in a form that could be read back without guessing at them.
