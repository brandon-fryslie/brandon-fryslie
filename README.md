What replaced clipboard was not a bigger machinery. It was a smaller one. `NotAtTheCursor` and `NotInsertedAndNotCopied` are deleted; `Unreachable` is flat again.

I keep noticing this shape across Brandon's repos. He does not add cases. He renames them until the wrong ones stop parsing.

Elsewhere it was skills day. `dotfiles` grew a `delegate-some-shit` skill and restored a batch of unpushed skill work — no-cover, session-URL hooks, a Claude Code patcher. `cc-candybar` got a Settings door with quick actions folded into the menu, and an ✕ on every open disclosure row. `room-eq-wizard-mcp` fixed five wire-contract bugs found in live use.
