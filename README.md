## Selected Projects

<!-- SELECTED-PROJECTS:START -->

Five of these are moving parts of one Claude Code setup: cc-hands handles voice, vhid screen control, cc-candybar the statusline, memento the session handoff, and lit the tickets.

<table>
<tr>
<td width="50%" valign="top">

### [cc-hands](https://github.com/promptctl/cc-hands)
**Python · 1★**

Hands-free Claude Code. You speak; a mediating agent cleans up what you said, types it into the right session, watches what comes back, and tells you about it. Runs on macOS on Apple silicon.

This week: TLS termination for `api.anthropic.com` moved in-process, and CI runs as five parallel five-minute jobs.

### [low-talker](https://github.com/promptctl/low-talker)
**Swift · 2★**

Push-to-talk dictation for macOS: hold a key, speak, release, and the words appear at the cursor. The speech model lives inside the app and audio never leaves the machine.

`brew install --cask promptctl/tap/low-talker`

This week: alpha.11 and alpha.12 cut, and iTerm2 no longer ran continued words together or capitalized them mid-sentence.

### [vhid](https://github.com/promptctl/vhid)
**Swift · Apache-2.0 · 2★**

A virtual keyboard and mouse for macOS that the OS treats as real hardware, driven from a CLI or over MCP. Works where fake keystrokes get ignored — the lock screen, password prompts, a Terminal with Secure Keyboard Entry — with no per-app permission.

`brew install --cask promptctl/tap/vhid`

This week: 0.7.0 cut, with a Timeline on the machine's uptime clock and `doctor` naming each grant `look` needs.

</td>
<td width="50%" valign="top">

### [cc-candybar](https://github.com/promptctl/cc-candybar)
**TypeScript · MIT**

Powerline statusline for Claude Code — daemon-backed, config-driven, JSON5 DSL with hot-reloading. Shows session cost, context usage, git status, model info, and rate-limit utilization across concurrent sessions.

`pnpm dlx @promptctl/cc-candybar@latest install`

This week: a settings-menu redesign, a window lane that replaces Claude Code's own statusline, and ssh-aware URL clicks.

### [links-issue-tracker](https://github.com/promptctl/links-issue-tracker)
**Go · MIT · 3★**

An issue tracker that lives inside your git repo, built for AI agents to drive. The backlog ships with the code in an embedded Dolt database, so every ticket change is a versioned commit that travels through your git remotes.

`curl -fsSL https://raw.githubusercontent.com/promptctl/links-issue-tracker/master/scripts/install.sh | bash -s -- --latest-release`

This week: v0.28.0 cut; stored timestamps now sort as their instant does, and every writer takes `stamp.Instant`.

### [memento](https://github.com/promptctl/memento)
**Python · MIT**

A Claude Code plugin with four skills for the beginnings, middles, and ends of agent sessions: work a PR review to clean, write a handoff for the next session, journal what each session did, and move the context ceiling.

This week: 0.15.0 cut, with `finalize-session` handing off through `/compact` again on `--reset compact`.

</td>
</tr>
